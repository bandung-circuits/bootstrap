4 Open DSH Desktop and start asking

Find this icon and open the app:

Mac: Launchpad (the rocket in the Dock) · Windows: Start menu, type “DSH”

  1. Click Choose workspace and pick the ai-workspace folder (it is in your home folder).
  2. That’s it — the model and the key are already configured. Just ask, e.g. “find recent news about your topic and save a short summary to news.md”.
Already have DSH Desktop? Quit it completely before running the command

Close its window; on Windows, make sure it isn’t still running in the system tray. While the app is running it can hold onto its config files and block the command from updating them. On a fresh computer you can ignore this.

What the command actually did
  1. Installed DSH Desktop (pinned version {{DSH_VERSION}}, from its official GitHub releases) if it wasn’t already on the computer.
  2. Created ~/ai-workspace with workspace rules (AGENTS.md), a README, .gitignore and a NEXT-STEPS.md.
  3. Installed inside that folder everything the web tools need: a Python environment with crawl4ai, and the browser it uses.
  4. Enabled the crawl4ai web fetch & search tools (free, no key) through the official DSH MCP client.
  5. Configured the {{LABEL}} model provider: the Bailian API key (built into the command), the endpoint, and the content-safety header that prevents legitimate research material from being blocked at the platform layer (see the content-inspection guide).
  6. Selected {{MODEL}} as the default model and set the permission to Full Access, so the agent can work without prompting you.
