Get your API key

The bootstrap installer connects your AI workspace — DeepSeek Harness (dsh, recommended) or the VS Code + Claude Code alternative — to DeepSeek V4 Flash 0731. You need one API key from a provider. The installer auto-picks one based on your region, but you can override with --provider=. After install, paste the key into ~/ai-workspace/.dsh/.env (dsh) or ~/ai-workspace/.claude/settings.local.json (Claude Code) — or into the dsh Web UI (Settings → Models).

China · default

Alibaba Cloud Bailian (百炼)

Best for users in mainland China. Requires a Chinese payment method (Alipay) or entity.

  1. Open the Bailian console and sign in with an Alibaba Cloud account.
  2. Activate Model Studio (first-time gets a free quota).
  3. Go to API-Key Management and create an API key. Copy and save it.
International · default

Alibaba Cloud Model Studio (international)

For users outside China. Same DeepSeek V4 Flash 0731, via Alibaba Cloud's international Model Studio (Singapore entity, English UI, Visa/Mastercard).

  1. Open the international Model Studio console and register an Alibaba Cloud International account (email + international phone).
  2. Add a payment method (Visa/Mastercard) and activate Model Studio.
  3. Under API Keys, create a key and copy it.
Fallback

DeepSeek official

Direct connection to DeepSeek, no middleman. International credit card, pay-as-you-go, very cheap. Use if you prefer DeepSeek's own platform over Alibaba.

  1. Open platform.deepseek.com and register.
  2. Add a payment method and top up your balance.
  3. Under API Keys, create a key and copy it.
Fallback

OpenRouter

One key accesses many models. Slightly more expensive for DeepSeek (platform fee). Good if you already have an OpenRouter account or want to switch models later.

  1. Open openrouter.ai and sign up.
  2. Add credits (credit card).
  3. Under Keys, create and copy an API key.

Note: the exact Claude Code ↔ OpenRouter wiring is being finalized; until then the default international route is DeepSeek official.

Optional: Serper & Oxylabs MCP

The installer ships the free crawl4ai MCP (web fetch/search, no key). For heavier search needs you can add Serper or Oxylabs yourself — they need your own paid API keys. After bootstrap with Claude Code, edit ~/.claude/.mcp.json and add a serper-search or oxylabs entry with your keys, then restart Claude Code. (With dsh, add them as @deepseek-ai/dsh-mcp-client rows in ~/ai-workspace/.dsh/cordis.patch.yml — see design-dsh.md.)
