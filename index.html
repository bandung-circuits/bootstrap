Bootstrap your AI workspace

One command installs Visual Studio Code + Claude Code, backed by DeepSeek V4 Flash 0731 — cheap and capable. Built for learners with little IT background. Once it's set up, you can just ask the AI.

Run this in your terminal

Works on most Linux distributions and macOS (Apple Silicon and Intel).

curl -fsSL https://bandung-circuits.github.io/bootstrap/install.sh | bash

No curl? (e.g. minimal Ubuntu Server) Use wget instead:

wget -qO- https://bandung-circuits.github.io/bootstrap/install.sh | bash

Run this in PowerShell

Right-click Start → Terminal (or Windows PowerShell), paste, press Enter.

irm https://bandung-circuits.github.io/bootstrap/install.ps1 | iex

Windows via WSL (advanced)

If you prefer a Linux environment inside Windows: install WSL (wsl --install in PowerShell as admin, reboot), then inside WSL run the Linux command:

curl -fsSL https://bandung-circuits.github.io/bootstrap/install.sh | bash

No curl? Use wget -qO- https://bandung-circuits.github.io/bootstrap/install.sh | bash.

What it does

  1. Detects your OS and region, picks a model provider (China → Alibaba Bailian; elsewhere → DeepSeek official).
  2. Installs Visual Studio Code and the Claude Code extension (the extension bundles its own CLI — no separate Node.js or CLI install).
  3. Configures the backend to DeepSeek V4 Flash 0731 — you'll paste your API key when asked.
  4. Installs the crawl4ai MCP (web fetch & search, free, no key needed) via a pinned Python 3.10 venv.
  5. Creates a clean, self-contained ~/ai-workspace (config lives inside it) and opens VS Code there, so you can start immediately.

Need an API key? See the provider subscription guide.
