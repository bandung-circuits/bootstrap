DeepSeek Harness (dsh) — agent in your browser

Free and open source. After install, double-click start-dsh.sh in ~/ai-workspace and your browser opens the assistant at http://127.0.0.1:3080. Built for learners with little IT background: no VS Code, no IDE setup, no PATH.

irm https://bandung-circuits.github.io/bootstrap/dsh/install.ps1 | iex

On WSL (Windows Subsystem for Linux), install WSL first (wsl --install in PowerShell as admin, reboot), then run the Linux command inside WSL:

curl -fsSL https://bandung-circuits.github.io/bootstrap/dsh/install.sh | bash

What it does

  1. Detects your OS and region, picks a model provider (China → Alibaba Bailian; elsewhere → Alibaba Cloud Model Studio international).
  2. Installs Node.js (pinned LTS) and the dsh CLI (pinned version) — no admin rights needed.
  3. Wires the backend to DeepSeek V4 Flash 0731 and enables the crawl4ai MCP (web fetch & search, free, no key) through the official dsh MCP client.
  4. Creates a clean, self-contained ~/ai-workspace (all config lives inside it) and leaves a NEXT-STEPS.md telling you where to paste your API key.
  5. Starts the assistant — your browser opens http://127.0.0.1:3080.
