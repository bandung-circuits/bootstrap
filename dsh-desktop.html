DSH Desktop workspace

You already installed DSH Desktop (https://dshdesktop.com/en/, macOS or Windows). One command prepares a ready AI workspace for you — no Node, no terminal apps to manage.

Run this in your terminal macOS

Terminal is in Applications → Utilities. Paste, press Enter.

curl -fsSL https://bandung-circuits.github.io/bootstrap/dsh-desktop/prep.sh | bash

Windows — run this in PowerShell

Right-click Start → Terminal (or Windows PowerShell). Paste, press Enter.

irm https://bandung-circuits.github.io/bootstrap/dsh-desktop/prep.ps1 | iex

What it does

  1. Creates ~/ai-workspace (Windows: C:\Users\<you>\ai-workspace) and seeds it with workspace rules (AGENTS.md), a README, .gitignore and a NEXT-STEPS.md.
  2. Installs uv/uvx (the small runner the crawl4ai MCP uses; it lives in your home folder, no administrator needed).
  3. Enables the crawl4ai MCP server (web fetch & search, free, no key) through the official DSH MCP client — the same mechanism every DSH app uses.
  4. Leaves the model backend key to you, one paste in the app: Settings → Models.

Then what?

  1. Open DSH Desktop → Settings → Models → paste your DeepSeek API key.
  2. Click Choose workspace and pick ~/ai-workspace.
  3. Ask the AI anything, e.g. "create a hello.py and run it". The first web search pulls a small helper environment automatically.
Source & docs: github.com/bandung-circuits/bootstrap · DSH Desktop is a community desktop app; DeepSeek Harness is by deepseek-ai.
