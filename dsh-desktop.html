DSH Desktop workspace

Free, open source, runs on your own computer. One command — about 5 minutes — and your AI workspace is ready, backed by DeepSeek V4 Flash 0731. Then just ask the AI.

  1. Open the black window
    Mac: press ⌘+Space, type Terminal, press ⏎ Enter
    Windows: press the ⊞ Win key, type PowerShell, press ⏎ Enter
  2. Click the green button to copy
    The button is just below.
  3. Paste it there, press Enter, wait
    Paste into the black window, press ⏎ Enter, then wait about 5 minutes.
Terminal — macOS
$ curl -fsSL https://bandung-circuits.github.io/bootstrap/dsh-desktop/setup.sh | bash

You don’t need to understand this command — just copy it.

Using Windows instead? Switch to Windows

PowerShell — Windows
PS C:\Users\you> iex (curl.exe -sL https://bandung-circuits.github.io/bootstrap/dsh-desktop/setup.ps1 | Out-String)

You don’t need to understand this command — just copy it.

Using a Mac instead? Switch to macOS

DSH Desktop doesn’t support your operating system yet.
It currently works on macOS and Windows only. If you’re on Linux (or anything else), the VS Code + Claude Code option works on your system — or check back later.

After you press Enter, the black window will scroll a lot of English text. That is normal — it is installing. Do nothing, just wait until it stops (about 5 minutes, depending on internet speed).

how it ends when it worked
==> Done. Your AI workspace is ready at ~/ai-workspace ============================================ Setup complete! Now open the DSH Desktop app (Mac: Launchpad | Windows: Start menu) ============================================

When the window ends with this, it worked. If it shows a red ERROR line instead, scroll up — the first error usually says what went wrong.

4 Open DSH Desktop, add your model key, start

Find this icon and open the app:

Mac: Launchpad (the rocket in the Dock) · Windows: Start menu, type “DSH”

  1. The app needs a model service behind it — a small paid subscription. Recommended: OpenRouter; Alibaba Cloud Model Studio (international) also works well. Open Settings → Models and paste your API key.
  2. Click Choose workspace and pick ~/ai-workspace.
  3. That’s it — just ask, e.g. “find recent news about your topic and save a short summary to news.md”. The first web search pulls a small helper environment automatically.
Already have DSH Desktop? Quit it completely before running the command

Close its window; on Windows, make sure it isn’t still running in the system tray. The app can hold onto its config files and block the command from updating them. On a fresh computer you can ignore this.

What the command actually did
  1. Installed DSH Desktop (pinned version v0.9.2, from its official GitHub releases) if it wasn’t already on the computer.
  2. Created ~/ai-workspace (Windows: C:\Users\<you>\ai-workspace) with workspace rules (AGENTS.md), a README, .gitignore and a NEXT-STEPS.md.
  3. Installed inside that folder everything the web tools need: a Python environment with crawl4ai, the browser it uses, and a helper.
  4. Enabled the crawl4ai web fetch & search tools (free, no key) through the official DSH MCP client, so the assistant can read web pages.
  5. Left one step to you: paste the model API key in the app (Settings → Models).
About DSH Desktop

DSH Desktop is a community desktop app for the open-source DeepSeek Harness (by deepseek-ai). Prefer coding in an IDE? The VS Code + Claude Code setup works on Linux, macOS and Windows.
