DSH Desktop workspace

A ready AI workspace for DSH Desktop in one command — free, open source, runs on your own computer. First install the app, then run the command.

Step 1 — Install DSH Desktop and set up a model subscription

Download the app for your computer from dshdesktop.com/en/ and install it normally (drag to Applications on macOS, run the installer on Windows). Supported: macOS (Apple Silicon and Intel) and Windows. Linux is not supported yet.

The app needs a model service behind it. Sign up for one (a small paid subscription) and paste the key into Settings → Models inside the app. Recommended: OpenRouter; Alibaba Cloud Model Studio (international) also works well.

Step 2 — Run one command

Before you run the command: quit DSH Desktop completely (close its window; on Windows, make sure it isn’t still running in the tray). The app can hold onto its config files and block the command from updating them.

Then open a terminal (macOS: Applications → Utilities → Terminal) or PowerShell (Windows), paste the command for your system, press Enter.

curl -fsSL https://bandung-circuits.github.io/bootstrap/dsh-desktop/prep.sh | bash
iex (curl.exe -sL https://bandung-circuits.github.io/bootstrap/dsh-desktop/prep.ps1 | Out-String)

DSH Desktop doesn’t support your operating system yet.
It currently works on macOS and Windows only. If you’re on Linux (or anything else), the VS Code + Claude Code option works on your system — or check back later.

Then what?

  1. Open DSH Desktop → Settings → Models → paste your API key.
  2. Click Choose workspace and pick ~/ai-workspace.
  3. Ask the AI anything, e.g. "find recent news about <your topic> and save a short summary to news.md", or "draft a one-page briefing note about <an event> in plain language". The first web search pulls a small helper environment automatically.
What the command actually did (tap to expand)
  1. Created ~/ai-workspace (Windows: C:\Users\<you>\ai-workspace) with workspace rules (AGENTS.md), a README, .gitignore and a NEXT-STEPS.md.
  2. Installed inside that folder everything the web tools need: a Python environment with crawl4ai, the browser it uses, and a helper.
  3. Enabled the crawl4ai web fetch & search tools (free, no key) through the official DSH MCP client, so the assistant can read web pages.
  4. Left one step to you: paste the model API key in the app (Settings → Models).

About DSH Desktop

DSH Desktop is a community desktop app for the open-source DeepSeek Harness (by deepseek-ai). Prefer coding in an IDE? The VS Code + Claude Code setup works on Linux, macOS and Windows.
