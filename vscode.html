VS Code + Claude Code

One command installs Visual Studio Code + Claude Code, backed by DeepSeek V4 Flash 0731. About 5–10 minutes, then just ask the AI.

  1. Open the black window
    Mac: press ⌘+Space, type Terminal, press ⏎ Enter
    Linux: press Ctrl+Alt+T
    Windows: press the ⊞ Win key, type PowerShell, press ⏎ Enter
  2. Click the green button to copy
    The button is just below.
  3. Paste it there, press Enter, wait
    Paste into the black window, press ⏎ Enter, then wait about 5–10 minutes.
Terminal — macOS / Linux
$ curl -fsSL https://bandung-circuits.github.io/bootstrap/install.sh | bash

You don’t need to understand this command — just copy it.

After you press Enter, the black window will scroll a lot of English text. That is normal — it is installing. Do nothing, just wait until it stops.

how it ends when it worked
==> Done. Almost ready! One step left: add your API key. See ~/ai-workspace/NEXT-STEPS.md Then VS Code opens in ~/ai-workspace Setup finished.

When the window ends with this, it worked. If it shows a red ERROR line instead, scroll up — the first error usually says what went wrong.

Using Windows instead? Switch to Windows

You don’t need to understand this command — just copy it.

After you press Enter, the black window will scroll a lot of English text. That is normal — it is installing. Do nothing, just wait until it stops.

>_how it ends when it worked─□✕
All steps completed. Almost ready! One step left: add your API key. See ~/ai-workspace/NEXT-STEPS.md Then open VS Code in ~/ai-workspace Setup finished.

When the window ends with this, it worked. If it shows a red ERROR line instead, scroll up — the first error usually says what went wrong.

Using Mac or Linux instead? Switch to macOS / Linux

4 VS Code opens by itself — add your API key, start

When the command ends, VS Code opens by itself in the ai-workspace folder. It will show a file called NEXT-STEPS.md with the one remaining step:

  1. Follow NEXT-STEPS.md: get an API key (see the provider subscription guide) and paste it where the file says.
  2. Then click the Claude Code icon in the right sidebar and just ask — e.g. “find recent news about your topic and save a short summary to news.md”.
What the command actually did
  1. Detects your OS and region, picks a model provider (China → Alibaba Bailian; elsewhere → Alibaba Cloud Model Studio international).
  2. Installs Visual Studio Code and the Claude Code extension (the extension bundles its own CLI — no separate Node.js or CLI install).
  3. Configures the backend to DeepSeek V4 Flash 0731 and leaves a NEXT-STEPS.md telling you where to paste your API key — the installer never blocks on a prompt.
  4. Registers the crawl4ai MCP (web fetch & search, free, no key needed) — it runs from the published package via uvx, so there's nothing to clone or build.
  5. Creates a clean, self-contained ~/ai-workspace (config lives inside it) and opens VS Code there, so you can start immediately.
No curl? (minimal server) — or Windows via WSL (advanced)

On a minimal Ubuntu Server without curl, use wget instead:

>_Terminal (WSL)─□✕
$ wget -qO- https://bandung-circuits.github.io/bootstrap/install.sh | bash

On Windows you can instead run Linux inside Windows (WSL): in PowerShell run wsl --install as administrator and reboot, then run the macOS/Linux command above inside WSL.

Prefer to set it up yourself, step by step?

This script is just a shortcut — it automates the same steps you'd do by hand. If you'd rather walk through it manually (and understand each piece along the way), the Tricontinental Institute published two clear, illustrated guides:

  • Install & set up Claude Code in Visual Studio Code — the basics, step by step with screenshots.
  • Connect Claude Code to alternative APIs — how the model-provider wiring works (the exact mechanism this script automates).

Worth reading even if you use the script — you'll see how the pieces fit together, and how to switch providers or tweak the setup later.
